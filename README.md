# Smart Document

A Python document-processing project that uses Tesseract OCR to extract text from PDF documents. Future development will add LLM API integration for document analysis and structured data extraction.

## Current Features

- Opens PDF documents using PyMuPDF
- Converts PDF pages into images
- Extracts text from images using Tesseract OCR
- Processes scanned PDF documents

## Requirements

- Python 3.14+
- Tesseract OCR

Python packages:

- PyMuPDF
- Pillow
- pytesseract
